# Ourfit (Удвох)

Сайт для тренувань на двох: бібліотека парних вправ, конструктор тренувань із таймером, календар із відмітками для кожного та вкладка «Відновлення» (план після кесаревого з анімованими схемами вправ).

Один файл `index.html`, без збірки. Відкрийте його в браузері або розмістіть на GitHub Pages. Дані зберігаються в localStorage браузера.

Вкладка «Відновлення» містить загальні орієнтири, а не медичну пораду. Дозволи на перехід між фазами дає лікар.
